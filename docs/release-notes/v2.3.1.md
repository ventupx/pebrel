# Pebrel 2.3.1

## English

### Added

- Added One Dark as the default theme for new preferences, with matching terminal and interface colors. Existing saved theme choices are preserved.
- Added editing and deletion of saved custom themes. Deleting the active custom theme restores the default theme after confirmation.
- Added Chrome, Minimal and Tag styles for top tabs, available in Appearance settings.
- Added five cursor blinking styles: Blink, Smooth, Phase, Expand and Solid. The choices follow the interface language and retain compatibility with the existing blink preference.

### Fixed

- Kept output-copy controls aligned with the more compact terminal padding, and avoided extra redraws when hiding terminal panes.
- Fixed background refreshes restoring an extra full-window fill, which made opacity values of 50% and above appear opaque on Windows. Terminal and Settings backgrounds now follow the same opacity preference while text, icons and dialogs remain readable.

### Improved

- Top tabs follow their title widths up to a maximum width. Long titles remain stationary and gradually fade out at the end, with shell indicators kept on the right.
- Refined Chrome tab curves, spacing and content padding. Tag hover backgrounds use the same rounded shape and inset spacing as the active tab; One Dark uses quieter active lines and borders.
- Reduced unused space above top tabs and terminal content.
- Renamed the opacity setting to Window background opacity and updated its description in all eleven supported interface languages.

## 中文

### 新增

- 新增 One Dark 默认主题，统一终端与界面配色；已有用户保存的主题选择保持不变。
- 自定义主题支持再次编辑和删除；确认删除正在使用的自定义主题后，自动恢复默认主题。
- 顶部标签新增谷歌、简约和标签三种样式，可在外观设置中切换。
- 光标新增闪烁、平滑、渐变、伸缩和常亮五种显示方式；选项跟随界面语言，并兼容原有闪烁设置。

### 修复

- 终端顶部留白收紧后，输出复制按钮同步对齐正文；隐藏终端时不再因光标重置触发额外重绘。
- 修复背景刷新时恢复额外整窗底色，导致 Windows 下 50% 及以上不透明度看起来完全不透明的问题。终端与设置页背景现在同步跟随不透明度设置，文字、图标和弹窗继续保持清晰。

### 改进

- 顶部标签根据名称自动调整宽度，并保留最大宽度；超长名称保持静止，末尾逐渐淡出，Shell 类型标识保留在右侧。
- 优化谷歌样式的底部曲线、间距和内容留白；标签样式的悬浮背景与激活态采用一致的圆角和内缩间距，One Dark 的激活线和边框配色更协调。
- 收紧顶部标签上方和终端正文顶部的空白。
- 不透明度设置更名为“窗口背景不透明度”，并更新现有十一种界面语言的说明。
